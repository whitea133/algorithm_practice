# [#](https://programmercarl.com/hot100/0053.maximum-subarray.html#_53-最大子数组和)53. 最大子数组和

[力扣题目链接](https://leetcode.cn/problems/maximum-subarray/)

解题思路：https://programmercarl.com/hot100/0053.maximum-subarray.html

## 题解

**dp[i]：以 nums[i] 为结尾的最大连续子数组和为 dp[i]**。

**注意：最后的结果不是 dp[n-1]，而是整个 dp 数组中的最大值！** 因为最大子数组不一定以最后一个元素结尾。

所以在递推的过程中，用一个变量 result 记录 dp[i] 的最大值即可。

完整代码如下：

```cpp
class Solution {
public:
    int maxSubArray(vector<int>& nums) {
        if (nums.size() == 0) return 0;
        vector<int> dp(nums.size());
        dp[0] = nums[0];
        int result = dp[0];
        for (int i = 1; i < nums.size(); i++) {
            dp[i] = max(dp[i - 1] + nums[i], nums[i]); // 状态转移公式
            if (dp[i] > result) result = dp[i]; // result 保存dp[i]的最大值
        }
        return result;
    }
};
```

- 时间复杂度：O(n)
- 空间复杂度：O(n)
