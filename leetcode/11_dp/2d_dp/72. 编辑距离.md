# 72. 编辑距离

[力扣题目链接](https://leetcode.cn/problems/edit-distance/)

解题思路：https://programmercarl.com/algo/dynamic-programming/0072-edit-distance.html#%E7%AE%97%E6%B3%95%E5%85%AC%E5%BC%80%E8%AF%BE

## 题解

以上动规五部分析完毕，C++代码如下：

```cpp
class Solution {
public:
    int minDistance(string word1, string word2) {
        vector<vector<int>> dp(word1.size() + 1, vector<int>(word2.size() + 1, 0));
        for (int i = 0; i <= word1.size(); i++) dp[i][0] = i; // 注意是小于等于
        for (int j = 0; j <= word2.size(); j++) dp[0][j] = j; // 注意是小于等于
        for (int i = 1; i <= word1.size(); i++) { // 注意是小于等于
            for (int j = 1; j <= word2.size(); j++) { // 注意是小于等于
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else {
                    dp[i][j] = min({dp[i - 1][j - 1], dp[i - 1][j], dp[i][j - 1]}) + 1;
                }
            }
        }
        return dp[word1.size()][word2.size()];
    }
};
```

- 时间复杂度: O(n * m)
- 空间复杂度: O(n * m)
