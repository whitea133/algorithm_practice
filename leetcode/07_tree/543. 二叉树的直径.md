## 543. 二叉树的直径

题目：https://leetcode.cn/problems/diameter-of-binary-tree/description/?envType=study-plan-v2&envId=top-100-liked

## 题解

c++代码如下：

二叉树节点的高度：指从该节点到叶子节点的最长简单路径边的条数或者节点数（取决于高度从0开始还是从1开始）

这里的空结点的高度为0，叶子结点的高度为1.

````
class Solution {
    int ans;
    int treeDepth(TreeNode * root) { // 这里的Depth应该理解为高度：当前结点到叶子结点到距离。
        //先考虑最下层的空节点
        if(root == nullptr) { 
            return 0;
        }

        //考虑中间层的左边的深度以及右节点的深度
        int left = treeDepth(root -> left);
        int right = treeDepth(root -> right);

        //维护最大值，  对每个节点 ： 如果其 左边深度与右边深度之和 大于 当前最大值， 则令最大值等于它
        ans = max(ans, left + right);

        //返回给更上一层的深度
        //底层->中间层->上层->更上层
        return max(left, right) + 1;
    }

public:
    int diameterOfBinaryTree(TreeNode* root) {
        ans = 0;
        treeDepth(root);
        return ans;
    }
};
````
