# 240. 搜索二维矩阵 II

题目：https://leetcode.cn/problems/search-a-2d-matrix-ii/description/?envType=study-plan-v2&envId=top-100-liked

题解参考leetcode，直接对每一行二分查找。

## 题解如下

```
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        for (const auto& row: matrix) { // 这里必须要加引用&，不然每次循环都会复制一份，导致内存超限制。const建议加，怕不小心修改原矩阵的话。
            auto it = lower_bound(row.begin(), row.end(), target);
            if (it != row.end() && *it == target) {
                return true;
            }
        }
        return false;
    }
};

```
