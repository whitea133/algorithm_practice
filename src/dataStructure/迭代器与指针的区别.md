# 迭代器与指针 终极区别总结（刷题极简版）

## 一、偷懒核心理解（你可以永远这么记）

**迭代器 = 容器专用的「受限制的假指针」**

平时写代码、理解逻辑：**直接把迭代器当指针用完全没问题**。

相同点：

- `*it` 解引用取值 → 和 `*p` 一模一样

- `it->second` 访问成员 → 和指针 `p->` 一模一样

- `++it` 下移一位 → 和指针\+\+ 一模一样

## 二、两类迭代器 核心差异（最重要）

### 1\. map / unordered\_map / set 迭代器

**✅ 完全符合你的理解：只能一步一步移动的指针**

- 只支持：`++it`、`--it`

- 不支持：`it + n`、`it - n`、`end() - 1`

- 内存不连续，像链表，只能一步步挪

### 2\. vector / string 迭代器

**❌ 不满足“只能一步一步走”**

- 支持随机跳转：`it + 5`、`it - 2`

- 支持 `end() - 1`

- 可以和下标互相转换：`下标 = it - begin()`

- 本质等价数组指针，自由度最高

## 三、迭代器和原生指针 三大致命区别（刷题必避坑）

### 1\. 空值判断完全不同

- 指针无效：`nullptr`，判断：`if(p == nullptr)`

- 迭代器无效：**\.end\(\) 哨兵**，判断只能是：`if(it != mp.end())`

- ❌ 迭代器绝对不能和 nullptr 比较、不能 if\(it\)

### 2\. 运算规则不同

- 原生指针：随便 ± 数字

- map迭代器：只能前后一步，不能跳步

### 3\. 迭代器独有：迭代器失效

- vector增删元素后，旧迭代器会报废（野迭代器）

- 普通指针没有失效概念

## 四、begin\(\) / end\(\) 终极口诀

- **begin\(\)**：指向第一个真实元素，可解引用

- **end\(\)**：尾后虚拟哨兵（墙），**永远不能解引用、不能\-it\-\>**

- 遍历条件永远是：`it != end()`

## 五、find\(\) 固定模板（直接背）

所有 map/set 查找统一写法：

```Plain Text
auto it = mp.find(key);
if (it != mp.end())
{
    //找到，可用 it->first / it->second
}
```

## 六、for 循环不同情况下的迭代器（新增小节）

> 
> 重点区分：普通迭代器 for 循环 vs 范围 for `for(auto x : container)`

### 1. 显式迭代器 for 循环（`begin()/end()`）

```
// it 是真正迭代器（类似假指针），使用 -> 访问成员
for (auto it = mp.begin(); it != mp.end(); ++it)
{
    // it 是迭代器，访问成员用 ->
    cout << it->first << it->second;
}
```

- `it`：迭代器对象，模拟指针；
- 访问成员：`it->first`、`it->second`；
- 可以做 `++it`、`--it`；unordered_map 不支持`it+n`。

### 2. 范围 for 循环 `for(auto x : mp)`

```
// x 不是迭代器！是容器内部存的**pair对象**（值/引用）
for (auto& x : mp)
{
    // 对象，用 . 点访问成员，不是 ->
    cout << x.first << x.second;
}
```

- 编译器内部自动拿 `begin()/end()`、生成迭代器，但**你拿到的不是迭代器，是解引用之后的元素对象**；
- ❌错误写法：`x->second`；✅正确：`x.second`；
- 建议写 `auto& x` 使用引用，避免拷贝。

### 3. 两种写法对照（以 unordered_map 为例）

表格

| 写法 | 变量是什么 | 访问成员符号 |
| --- | --- | --- |
| `for(auto it = mp.begin();... )` | 迭代器（假指针） | `it->first` / `it->second` |
| `for(auto& p : mp)` | pair<const K,V> 对象引用 | `p.first` / `p.second` |

> 
> 高频踩坑：题目 49 字母异位词分组报错，就是**范围 for 里误用 `->`，应该用 `.`**。

### 4. 补充：不能迭代的容器

`stack`、`queue`、`priority_queue`，没有`begin()`/`end()`，**既不能用迭代器 for，也不能用范围 for**。

## 七、一页纸终极总结

1. 偷懒理解：**迭代器 = 受限指针**
2. map 迭代器：**只能一步一步走**
3. vector 迭代器：**可以随便跳步，等价数组指针**
4. 无效判断不用空指针，只用 `!= end()`
5. end () 是墙，不是元素，绝对不能取值
6. ⚠区分两种 for：迭代器用`->`；范围 for 拿到对象，用`.`。
