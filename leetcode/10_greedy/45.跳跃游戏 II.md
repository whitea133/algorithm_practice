#  45.跳跃游戏 II

[力扣题目链接](https://leetcode.cn/problems/jump-game-ii/)

解题思路：https://programmercarl.com/algo/greedy/0045-jump-game-ii.html#%E7%AE%97%E6%B3%95%E5%85%AC%E5%BC%80%E8%AF%BE

## 题解

C++代码如下：（详细注释）

```cpp
class Solution {
public:
    int jump(vector<int>& nums) {
        // 数组只有一个元素，起点就是终点，不需要跳
        if (nums.size() == 1) return 0;

        int curDistance = 0;    // 当前这一跳，能够抵达的最远位置
        int ans = 0;            // 已经跳的步数
        int nextDistance = 0;   // 在【当前可达范围内】，再跳一步能到达的最远位置

        // i遍历：只在「当前这一跳能到达的区间」里扫描，寻找下一跳的最远点
        for (int i = 0; i < nums.size(); i++) {
            // 从i位置起跳，更新下一跳能冲到的最远距离
            nextDistance = max(nums[i] + i, nextDistance);

            // i走到了【当前这一跳的边界】，必须要跳出去，开启新的一跳
            if (i == curDistance) {
                ans++;                      // 执行一次跳跃，步数+1
                curDistance = nextDistance; // 更新边界：现在新一跳可以到 nextDistance

                // 下一跳已经可以够到最后一个下标，任务完成，直接退出，不要再计数
                if (nextDistance >= nums.size() - 1)
                    break;
            }
        }
        return ans;
    }
};

```

- 时间复杂度: O(n)
- 空间复杂度: O(1)
