虚拟头节点的作用很简单

1. 位了不用特殊处理head头节点情况
2. 为了最后返回一个完整的链表结果。

虚拟头节点的定义方法:

常常就是: return dmmyHead->next;

```
ListNode* dummyHead = new ListNode(0);
```

当时一定要注意要先:

dmmyHead->next = head; // 先让虚拟头节点的next指针指向原本的一个链表.

还有就是后面新创建的指针，一般全都指向虚拟头节点:

````
ListNode* slow = dummyHead;
ListNode* fast = dummyHead;
````



# 虚拟头结点（dummy / 哑节点）

`ListNode* dummy = new ListNode(0);` **作用：统一头节点的特殊情况，不用单独写 if 判断处理头结点被修改的场景**

## 什么时候需要

链表操作，如果**头节点本身会被删掉、会被替换**：

- 删除链表节点（比如删除倒数第 N 个）
- 合并两个链表
- 删除重复元素

如果不用 dummy：

> 要写一堆 `if(head == xxx)` 判断，区分是不是操作头结点，逻辑容易乱，还容易漏边界。

## 核心 2 点总结

1. ✅**消除头结点特殊分支**，所有节点一套逻辑，减少 if，减少 bug。
2. ✅即使整个链表全部删空，`dummy->next` 自动等于`nullptr`，不会空指针异常。
