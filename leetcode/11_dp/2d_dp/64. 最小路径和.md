# 64. 最小路径和

题目链接：https://leetcode.cn/problems/minimum-path-sum/description/?envType=study-plan-v2&envId=top-100-liked



## 题解 -- 很简单的动态规划，借助之前不同路径的思想即可

主要是先把边界填好。

```
class Solution {
public:
    int minPathSum(vector<vector<int>>& grid) {
        // dp[i][j] = min(dp[i-1][j] + grid[i][j], dp[i][j-1]+grid[i][j])
        int n = grid.size();
        int m = grid[0].size();
        vector<vector<int>> dp (n, vector<int> (m, 0));

        dp[0][0] = grid[0][0]; // 这里必须初始化
        for (int i = 1; i < n; i++) dp[i][0] = dp[i-1][0] + grid[i][0]; // 填好竖着的边界
        for (int j = 1; j < m; j++) dp[0][j] = dp[0][j-1] + grid[0][j]; // 填好横着的边界

        for (int i = 1; i < n; i++)
            for (int j = 1; j < m; j++)
            {
                dp[i][j] = min(dp[i-1][j] + grid[i][j], dp[i][j-1]+grid[i][j]);
            }

        return dp[n-1][m-1];
    }
};
```
