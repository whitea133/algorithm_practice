LeetCode 49 字母异位词分组 刷题笔记（纯本题专属）

## 一、题目核心

**字母异位词定义**：字符组成、数量完全一致，仅排列顺序不同的字符串。

题目要求：将输入字符串数组中，所有异位词分为同一组，各组顺序无要求，同组字符串顺序无要求。

核心解题思想：**异位词排序后字符串完全一致**，可将排序后的字符串作为唯一分组标识。

## 二、AC 完整代码

```cpp
class Solution {
public:
vector<vector<string>> groupAnagrams(vector<string>& strs) {
        unordered_map<string, vector<string>> hashtable;
        for (auto str : strs)
        {
            string key = str;
            sort(key.begin(), key.end());
            // 核心语句：自动建组 + 存入原字符串
            hashtable[key].push_back(str);
        }
        // 收集所有分组结果
        vector<vector<string>> res;
        for (auto it = hashtable.begin(); it != hashtable.end(); ++it)
        {
            res.push_back(it->second);
        }
        return res;
    }
};
```

## 三、数据结构设计（本题核心）

```cpp
unordered_map<string, vector<string>> hashtable;
```

- **key（string）**：原字符串排序后的结果，作为异位词分组的唯一标识

- **value（vector\<string\>）**：存储当前分组下所有原始异位字符串

## 四、核心代码深度解析（必考坑点）

### 1\. 关键语句：`hashtable[key].push_back(str);`

拆分为两步底层逻辑（90%初学者不懂的核心）：

```cpp
// 第一步：执行 unordered_map 的 operator[]
vector<string>& ref = hashtable[key];
// 第二步：向分组容器追加元素
ref.push_back(str);
```

#### operator\[\] 核心特性（本题解题关键）

- 若 **key 已存在**：直接返回对应 value（vector）的引用

- 若 **key 不存在**：**自动插入该 key，并默认构造一个空的 vector\<string\>**，再返回空容器引用

⚠️ 重点：**仅执行 hashtable\[key\] 就会新增键值对**，和后续 push\_back 无关，这是本题需要的「无则新建分组」特性。

#### push\_back 作用

仅对 value 对应的 vector 追加原始字符串，**不会新增/删除哈希表的 key，不会改变哈希表总个数**。

补充：本题中 `push_back` 和`emplace_back` 效果完全一致，可互换。

## 五、unordered\_map 本题专属特性

- 底层为哈希表，增查平均时间复杂度 O\(1\)，效率高于 map

- **遍历顺序随机**：不遵循插入顺序、不遵循 key 排序顺序

- 适配本题：题目不要求分组顺序，仅要求同组聚合，因此可以放心使用

- 若题目要求分组按字典序排序，必须替换为有序红黑树容器 `map`

## 六、易错点 \& 避坑总结

### 1\. 哈希表 \[\] 运算符误区

unordered\_map 的 `[]` 不是数组下标（不支持数字索引），是**按 key 哈希查询**，存在「无则自动插入」的独有副作用。

### 2\. operator\[\] 和 find\(\) 场景区分（高频考点）

- **本题用 operator\[\]**：需要「不存在分组就自动新建空分组」

- **查询场景用 find\(\)**：仅查询、不新增 key（如两数之和），无自动插入副作用

### 3\. 遍历写法报错坑

范围 for 遍历哈希表时，拿到的是 **pair 对象**，只能用 `.` 访问成员，禁止用迭代器的 `->`：

```cpp
// 正确
for(auto& p : hashtable) res.push_back(p.second);
// 错误（编译报错：非指针类型）
for(auto& p : hashtable) res.push_back(p->second);
```

## 七、解题流程极简复盘

1. 遍历每一个原始字符串

2. 对字符串排序，生成统一分组 key

3. 利用哈希表自动新建分组特性，将原字符串归入对应组

4. 遍历哈希表，取出所有分组集合作为结果返回
