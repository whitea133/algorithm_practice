# 74. 搜索二维矩阵

[力扣题目链接(opens new window)](https://leetcode.cn/problems/search-a-2d-matrix/)

思路链接：https://programmercarl.com/hot100/0074.search-a-2d-matrix.html

## 1. 题解 -- 原理是基于二分查找的。就是多了利用下标映射，把它还原成最熟悉的一维二分查找。

代码（注意模版不是基于acwing的二分查找）：

```cpp
class Solution {
public:
    bool searchMatrix(vector<vector<int>>& matrix, int target) {
        int rows = matrix.size();
        int cols = matrix[0].size();
        int left = 0;
        int right = rows * cols - 1;

        while (left <= right) {
            int mid = left + (right - left) / 2;
            int row = mid / cols; // 商是行
            int col = mid % cols; // 余数是列
            int value = matrix[row][col];

            if (value < target) {
                left = mid + 1;
            } else if (value > target) {
                right = mid - 1;
            } else {
                return true;
            }
        }
        return false;
    }
};
```

## [#](https://programmercarl.com/hot100/0074.search-a-2d-matrix.html#复杂度分析)复杂度分析

时间复杂度：`O(log(m × n))`，在 `m × n` 个虚拟下标上进行二分查找。空间复杂度：`O(1)`。
