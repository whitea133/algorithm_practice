#  200. 岛屿数量

[题目链接](https://leetcode.cn/problems/number-of-islands/)

题目思路：https://programmercarl.com/algo/other/0200-number-of-islands-dfs.html

## 题解 -- 基于dfs的图的深度优先遍历

写一个dfs遍历函数，把一个陆地附近的陆地全都遍历。

然后主函数for循环一下，遇到一个陆地，就把其周围的陆地全部打标记，岛屿+1。

后面再遇到打过标记的陆地，直接跳过。

直到没有陆地为止。

注意进入dfs的时候，一定要记得标记`visited[x][y] = true`。很容易忘了。

代码如下：

```cpp
// 版本二
class Solution {
private:
    int dir[4][2] = {0, 1, 1, 0, -1, 0, 0, -1}; // 四个方向
    void dfs(vector<vector<char>>& grid, vector<vector<bool>>& visited, int x, int y) {
        if (visited[x][y] || grid[x][y] == '0') return; // 终止条件：访问过的节点 或者 遇到海水
        visited[x][y] = true; // 标记访问过
        for (int i = 0; i < 4; i++) {
            int nextx = x + dir[i][0];
            int nexty = y + dir[i][1];
            if (nextx < 0 || nextx >= grid.size() || nexty < 0 || nexty >= grid[0].size()) continue;  // 越界了，直接跳过
            dfs(grid, visited, nextx, nexty);
        }
    }
public:
    int numIslands(vector<vector<char>>& grid) {
        int n = grid.size(), m = grid[0].size();
        vector<vector<bool>> visited = vector<vector<bool>>(n, vector<bool>(m, false));

        int result = 0;
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < m; j++) {
                if (!visited[i][j] && grid[i][j] == '1') {
                    result++; // 遇到没访问过的陆地，+1
                    dfs(grid, visited, i, j); // 将与其链接的陆地都标记上 true
                }
            }
        }
        return result;
    }
};
```

## dir [4][2] 方向数组解析

```
int dir[4][2] = {0, 1,  1, 0,  -1, 0,  0, -1};
```

每一组 `{dx, dy}`，代表：**x 的变化量，y 的变化量**

> `nextx = x + dx` `nexty = y + dy`

> 注意：grid 二维数组

- `x` → 行号（上下）
- `y` → 列号（左右）

表格

| 下标 | dx   | dy   | 含义                                |
| ---- | ---- | ---- | ----------------------------------- |
| i=0  | 0    | +1   | **右**：行不变，列 + 1 → `(x, y+1)` |
| i=1  | +1   | 0    | **下**：行 + 1，列不变 → `(x+1, y)` |
| i=2  | -1   | 0    | **上**：行‑1，列不变 → `(x‑1, y)`   |
| i=3  | 0    | -1   | **左**：行不变，列‑1 → `(x, y‑1)`   |

遍历顺序：**右 → 下 → 上 → 左**，四个相邻，只走上下左右，**不包含斜角**。

内存写法等价完整书写（可读性更好，刷题推荐这么写）

```
int dir[4][2] = {
    {0, 1},   //右
    {1, 0},   //下
    {-1, 0},  //上
    {0, -1}   //左
};
```
