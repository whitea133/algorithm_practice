# 141.环形链表

[力扣题目链接](https://leetcode.cn/problems/linked-list-cycle/submissions/)

解题思路：https://programmercarl.com/algo/other/0141-linked-list-cycle.html#%E6%80%9D%E8%B7%AF

## 题解 -- 基于快慢指针来判断环形链表。不需要虚拟头节点

C++代码如下

```cpp
class Solution {
public:
    bool hasCycle(ListNode *head) {
        ListNode* fast = head;
        ListNode* slow = head;
        while(fast != NULL && fast->next != NULL) {
            slow = slow->next;
            fast = fast->next->next;
            // 快慢指针相遇，说明有环
            if (slow == fast) return true;
        }
        return false;
    }
};
```
