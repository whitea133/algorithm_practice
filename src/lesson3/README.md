# bfs 广度优先搜索, 常用分支限界法
bfs 可以用来搜索最短路径(路径权值都一样时)，因为如果一个叶子结点第一次搜到了，第二次又搜到了，那么这个肯定是第一次最短

只要问题是关于最短，最近，最小之类的，大概就是bfs

bfs模版:
```
queue <- 初始状态(把初始状态放到队列里面去)
while queue不空
{
    t <- 队头 (每次把队头拿出来)
    扩展队头t
}
```

其实这个说是模版, 其实就是分支限界法的队列式执行过程

# 树和图的存储
一般来说有两种存储方式
树是一种特殊的图，是无环联通图。因此只需要介绍图就行了。


## 1. 无向图(边无方向)
无向图也可以看成是特殊的有向图。只需要把建立两条方向的边就行了, a -> b, b -> a
所以只需要学有向图的存储就行了。

## 2. 有向图(边有方向)
有向图存储分为两大类:
1. 邻接矩阵: 其实就是开一个二维数组g[N][N], g[a][b]存储从 a 到 b 到边信息。有权重就是权重，无权重就存储bool值
   1. 如果是有重边的话，邻接矩阵是没办法存储有重边的。
   2. 空间复杂度是O(n^2), 比较适合稠密图
2. 邻接表: 就是用单链表来存储，用 N个点 就用N个单链表来存储。每个单链表存储这个点所有可以到达的点 
   1. 用头插法进行插入新节点，实现加入边
   2. 类似拉链法

# 树和图的遍历
分为两种方式：
1. 深度优先遍历
2. 广度优先遍历

由于树是一种特殊的图，所以我们只需要考虑图的遍历就行了。
由于无向图也是一种特殊的有向图，所以只需要考虑有向图的遍历就行了。

## 有向图的深度优先遍历
深度优先遍历就是我们要逮住一个起点，从后从这个起点一条路走到黑

```
// dfs 图/树的深度优先搜索
#include <iostream>
#include <cstring>
#include <algorithm>
using namespace std;

const int N = 100010, M = N * 2;

int n, m;
int h[N], e[M], ne[M], idx; // e[i] 表示下标为i的时候，对应图中的哪个结点，图中的节点是用字母表示的。相当于把idx转化成字母
bool st[N]; // 因为每个节点最多只遍历一次，因此要用一个布尔数组记录

// 边的添加 -- 代码模版
void add(int a, int b)
{
    e[idx] = b;
    ne[idx] = h[a];
    h[a] = idx;
}

// 深度优先搜索 -- 代码模版
void dfs(int u)
{
    st[u] = true; // 标记一下， 已经被搜过了

    for (int i = h[u]; i != -1; i = ne[i]) // 遍历一下 u 的所有出边
    {
        int j = e[i]; // e[i] 表示当前链表里的节点，对应图里面的编号是多少(编号是字母）。这里用 j 暂存
        if (!st[j]) dfs(j); // 如果 j 这个结点没有被搜索过，则继续 dfs 搜索
    }
}

int main()
{
    memset(h, -1, sizeof h);
    
    dfs(1);
}
```

# 拓扑序列(图的宽度优先搜索的一个应用)
注: 图的拓扑序列是针对有向图来说的，无向图是没有拓扑序列的!(同时也不是所有有向图多有拓扑序列的)

拓扑序列即一个序列满足所有边的起点都排在该边的终点前面。(所有的边都是从序列前指向序列后的)

可以证:
1. 明一个有向无环图，一定是存在拓扑序列的, 因此有向无环图也被称为拓扑图
2. 一个有向无环图，一定至少存在一个入度为0的点
3. 一个图的拓扑序列是不唯一的

所有入度为0的点，都可以作为拓扑序列的起点。

拓扑排序的思路如下：
```
queue <- 所有入度为0的点(把所有入度为0的点入队)

while (queue不为空)
{
    t <- 队头(每一次取出来队头)
    枚举 t 的所有出边, 比如 t -> j
    删掉 t -> j, j的入度d[j]--
    if (d[j] == 0) // d[j] == 0说明此时 j 前面所有的点都已经排好序了, 入度为0。此时 j 也可以作为起点入队了
        queue <- j
}
```

# 最短路问题
约定 n是点数, m是边数。当 m 和 n^2 差不多的时候，就是稠密图。
常见的最短路问题可以分为两大类:
1. 单源最短路: 求一个点到所有点的最短路问题。可以细分为以下两大类
   1. 所有边的权重都是正数
      1. 朴素的迪杰斯特拉算法。时间复杂度为 O(n^2), 比较适合边多的稠密图(m 和 n^2 一个级别)。m 和 n 一个 级别的叫稀疏图。
      2. 堆优化版的迪杰斯特拉算法。时间复杂度 O(mlogn)
   2. 存在负权重的(不一定可以得到最短路)
      1. Bellman-Ford 算法。 时间复杂度为 O(nm)
      2. SPFA 算法。时间复杂度一般为 O(m), 最坏为 O(nm), 可以看作是 Bellman-Ford 算法的优化(但不是所有情况下都可以用SPFA算法, 比如要求了不超过k条边)。SPFA算法要求不能有负环。基本上，只要没有负环，就可以用SPFA算法。
2. 多源汇最短路(源是指起点，汇是指终点): 起点和终点不确定，要求多次回答两点的最短距离，因此一般要求出所有情况。只有一种算法。
   1. Floyd算法。时间复杂度为 O(n^3)。也可以处理负权，当时不能有负权回路。
 
最短路问题的难点在在于建图，将问题抽象为对应的最短路算法。

## 1. 朴素版的狄杰斯特拉
算法思路：
1. 第一步，先初始化
   1. dis[1] = 0, 1号点到起始点的距离为0。 
   2. dis[i] = +00, 其他点到起始点的距离为正无穷。
2. 下一步开始迭代循环，循环 n 次。for i : 1 ~ n
   1. Si集合为所有当前已经确定最短路的点
   2. 循环第一步，找到不在S中的距离最近的点: t <- 不在S中距离最近的点
   3. 第二步, 把这个 t 加到 s 里面去： s <- t
   4. 第三步, 用t更新其他点的距离: 就是看一下 dis[x] > dis[t] + w（从1号点走到x的距离，是否大于从1号点走到t，再加上t走到x点距离w）, 大于就更新
3. 循环一次确定一个点的最短距离，循环 n 次 就确定 n 个点的最短距离。

## 4. SPFA算法
SPFA算法是对bellman-ford算法的优化。

通过使用队列，来记录dist变小过的结点。

1. 每次dist变小的结点，都要加入到队列中。再每次取出队头的结点，来更新与该结点相连的点的dist。

2. 因为 dist[b] = min(dist[b], dist[a] + w[i]), 只有上一次的 dist[a] 变小的时候，dist[b] 才有可能会被更新。否则没有必要更新。

3. 如果dist[b]，被更新了，则说明可将 b 加入到队列中，重复执行前面的 流程1

代码实现和堆优化的dijkstra特别像。

## 5. Floyd 算法
用邻接矩阵d[N][N]来存储所有的边。d[i][j] 表示从 i 到 j 的最短路长度。


然后floyd算法用三重循环，都是从 1 ~ n, 每次更新一遍 dist[i][j] = min(d[i][j], d[i][k] + d[k][j])
```
for (k = 1; k <= n; k++)
   for (i = 1; i <= n; i++)
      for (j = 1; j <= n; j++)
         dist[i][j] = min(d[i][j], d[i][k] + d[k][j]);
```

注意必须是先循环 k ，后面的 i 和 j 可以换顺序

# 最小生成树问题
最小生成树问题一般都是无向图, 边的正负都没关系，算法都可以处理，可以有环(图就是有环的)，照样可以处理。

注意：
- 连通无向图 → 一定存在最小生成树（可以有多棵 MST，总权值一样）
- 不连通的无向图 → 不存在最小生成树

算法分类：
1. Prim算法(加点法)
   1. 稠密图用 朴素版Prim算法 O(n^2)
   2. 稀疏图用 堆优化的Prim算法 O(mlogn)。一般不常用，所以不讲了。
2. 克鲁斯卡尔算法(加边法)
   1. 时间复杂度为 O(mlogm)
3. 一般的算法选择思路：稠密图(m >= n^2)用 朴素版Prim算法，稀疏图(m <= n^2)用 克鲁斯卡算法

## 1. 朴素版Prim算法(很像dijkstra算法)
算法思路：
1. dist[i] <- +00 把所有距离初始化为正无穷
2. for (i = 0; i < n; i++) n次迭代
   1. t <- 找到集合外最近的点(集合s为当前已经找到的点的联通块)
   2. 用 t 更新其他到 "集合" 的距离 (这是和dijkstra不同的地方)
   3. st[t] = true

## 2. kruskal算法
不需要用邻接矩阵和邻接表，只需要开结构体存所有的边即可。

1. 第一步：先将所有边按权重，从小到大排序。直接调用sort函数就行(快速排序)
2. 第二步：枚举每条边a, b, 权重为c。
   1. 如果当前 a 与 b 不连通，则将这条边加入到集合里面
