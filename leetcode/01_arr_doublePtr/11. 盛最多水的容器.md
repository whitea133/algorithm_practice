# 11. 盛最多水的容器

[题目链接](https://leetcode.cn/problems/container-with-most-water/)

解题思路：https://programmercarl.com/hot100/0011.container-with-most-water.html

## 1. 题解--双指针（要背），模拟过程

核心是利用从两边完中间走，利用某一些指针没必要移动进行减枝

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int l = 0;
        int r = height.size() - 1;
        int result = 0; // 最大水量
        while(l < r) {
            int t = (r - l) * min(height[l], height[r]); // 去盛水量 
            result = max(result, t); // 获取最大水量
            if(height[l] < height[r]) l++;
            else r--;     
        }
        return result;
    }
};
```
