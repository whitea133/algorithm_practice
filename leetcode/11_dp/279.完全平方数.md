#  279.完全平方数

[力扣题目链接](https://leetcode.cn/problems/perfect-squares/)

思路：https://programmercarl.com/algo/dynamic-programming/0279-perfect-squares.html#%E7%AE%97%E6%B3%95%E5%85%AC%E5%BC%80%E8%AF%BE

## 题解 -- 类似完全背包问题、零钱兑换问题

```cpp
// 版本一
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n + 1, INT_MAX);
        dp[0] = 0;
        for (int i = 0; i <= n; i++) { // 遍历背包
            for (int j = 1; j * j <= i; j++) { // 遍历物品
                dp[i] = min(dp[i - j * j] + 1, dp[i]);
            }
        }
        return dp[n];
    }
};
```

- 时间复杂度: O(n * √n)
- 空间复杂度: O(n)

更好的理解：

```
class Solution {
public:
    int numSquares(int n) {
        vector<int> dp(n+1, INT_MAX); // 注意是n+1。因为dp[n]就是和为 n 的完全平方数的最少数量
        dp[0] = 0;
        for (int i = 0; i <= n; i++) // 注意是 i <= n
            for (int j = 1; j * j <= i; j++) // 注意是 j * j <= i
            {
                dp[i] = min(dp[i], dp[i - j * j] + 1);
            }


        return dp[n];
    }
};
```
