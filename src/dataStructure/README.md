## 3.2 并查集
含有的操作如下：
1. 将两个集合合并
2. 询问两个元素是否在一个集合当中

基本原理：每个集合用一棵树来表示。树根的编号就是整个集合的编号。每个节点存储
它的父节点，p[x]表示x的父节点
- 问题1：如何判断树根：if (p[x] = = x)
- 问题2：如何求x的集合编号：while(p[x]!= x) x = p[x];
  - 问题有优化方式：就是在完成一次查询x集合编号之后，将整个搜索路径上的节结点的父结点都改成查到的集合编号。后续其他结点就不用一步一步查询了，直接跳跃，实现 O(1) 时间复杂度。即路径压缩优化
- 问题3：如何合并两个集合：px 是x的集合编号，py是y的集合编号。p[x] = y

# 4. 堆（是一个完全二叉树）
完全二叉树就是最后一层从左到右排列，最后一层以上的都是满的
堆要实现的操作(用堆的两个基本操作完成，以小顶堆为例)：
1. 插入一个数
   1. 在堆的最后一个为止插入x，然后不断地up往上移，即up操作
2. 求集合当中的最小值
   1. 小根堆中就是根结点，即数组中第一个元素
3. 删除最小值
   1. 用堆最后一个元素覆盖堆顶，然后堆的size-1，最后将新的堆顶元素down下去即可
4. 删除任意一个元素
   1. 同样用堆最后一个元素覆盖要删除的第k个元素，然后size-1，最后判断第k个元素是变大了还是小了，小了就up，大了就down，不变就不变。无脑方法，就是直接down(k)，up(k)都写上，反正最终只会执行一个。
5. 修改任意一个元素
   1. 和第四个一样，把第k个元素的值改成x，然后down(k)，up(k)都写上就行了。

我们以小根堆为例，满足性质：每一个点都是小于等于左右儿子的，因此根结点就是整个树中的最小值。

## 4.1 堆的存储方式与基本操作
我们用一维数组来存储堆，其中数组第一个元素为根结点(默认下标从1开始，不然下面的儿子公式不成立)。
- x的左儿子为：2x
- x的右儿子为：2x+1

堆的**基本**操作有两个：
- 第一个是down(x)：把一个结点往下移(当一个数字变大的时候，就要在小根堆中下移，直到不能再移)
  - 先比较当前数与其左右子结点，与其中最小的一个进行交换位置，不断执行该步骤，直至不能交换为止。
- 第二个是up(x)：把一个结点往上移(当一个数字变小的时候，就要在小根堆中上移，知道不能再移动)
  - 比较当前数与父结点的大小，如果比父结点小则交换位置，直至不能交换为止。
- 以上两个操作和时间复杂度都和树度高度有关，因此是O(logn)

# 5. 哈希表
哈希表的作用：常用于将大空间(0~1e9) 映射到小空间(0~1e5)

存储方式有两种:
1. 开发寻址：就用一个一维数组，然后先找一个位置，如果有元素了，就放在下一个位置，以此类推，直到找到位置
   1. 该方法的一维数组规模，通常要求原来的问题规模的2～3倍(原来的问题规模指的是最多要在数组中插入多少个数)，然后使用最接近该数两倍后的质数
2. 拉链法：在原来一维数组上，拉一个拉链下来。
   1. 此方法的一维数组规模要找最接近问题规模大小(原来的问题规模指的是最多要在数组中插入多少个数)的质数

查找质数的算法代码：
```
for (int i = 100000; ;i++)  // 这里的 i = 100000,是假设问题规模为 0 ～ 1e5
{
   bool flag = true;

   for (int j = 2; j * j <= ; j++)
   {
      if (i % j == 0)
      {
         flag = false;  // 判断出不是质数
         break;   // 推出判断。当前的i不是质数，i+1判断下一个数
      }
      
      if (flag)
      {
         cout << i << endl;
         break;
      }
   }
}
```

一般要实现的操作只有两种：
1. 插入
2. 查找
3. 另外若有删除，一般就是给某个点打上一个删除标记，后面识别到是删除的就跳过就行。

补充知识：迭代器的本质
```
vector<int> v = {10,20,30};
auto it = v.begin();
// it 等价于 &v[0]  （数组首元素地址）
*it 等价于 v[0]
++it 等价于 it = it + 1; 指针后移一位
```

vector支持比较运算，按照字典序，比如 4 个 3 小于 3 个 4。可以直接用 < 判断是否小于。

注意有一个倍增思想。

遍历一个vector的代码写法：
```
// 写法1
for (int i = 0; i < a.size(); i++) cout << a[i] << ' ';

// 写法2: 迭代器写法
for (vector<int>::iterator i = a.begin(); i != a.end(); i++) cout << *i << ' '; // 注意 i 是迭代器变量, *i 才是元素  

// 注意上面的迭代器类型vector<int>::iterator 可以改成 auto，让程序自行推断

// 写法3
for (auto x : a) cout << x << ' '; // 这个底层是使用迭代器实现的, 就是和写法2一样的



```

## 6.7 set, map, multiset, multimap: 都是基于二叉平衡树(红黑树)现的, 本质是动态维护有序序列
注：使用前必须先 `#include <set>` 或 `#include <map>`

set里面不能有重复元素(如果插入了重复元素，那这个操作就会被忽略掉)，multiset里面可以有重复元素。

### 6.7.1 set 和 multiset
1. size()
2. empty()
3. clear()
4. begin() / end() 支持 ++ , -- 操作
5. insert() 插入一个数 
6. erase()
   1. 如果输入的是一个数，那么就删除所有x。时间复杂度 O(k + logn)，k为x的个数。
   2. 如果输入是一个迭代器，那么就删除这个迭代器
7. find() 查找一个数，如果不存在，则返回end()迭代器
8. count() 返回某一个数的个数(如果是set则只会是0或1，mulset则会有多个)
9.  lower_bound(x) 返回 大于等于x 的最小的数的迭代器。
10. upper_bound(x) 返回 大于x 的最小的数的迭代器。

### 6.7.2 map 和 multimap
注: 使用前必须 `#include <map> ` 

map里面有两个东西，是把前一个东西，映射到后一个

1. size()
2. empty()
3. clear()
4. begin() / end()
5. insert() 插入的数必须是一个pair，因为map有两个数据
6. erase() 输入的参数是pair或者迭代器
7. find()
8. [] map类似数组的操作，时间复杂度是O(logn)的，而数组是O(1)的，更快一点。
9. lower_bound()
10. upper_bound()

map 使用例子
```
map<string, int> a;

// 可以类似数组一样操作map
a["yxc"] = 1; // 直接赋值
cout << a["yxc"] << endl; // 直接像数组一样取map的第二元素

```
