# 简要规律 & 记忆方法

## 核心本质

看：**`left == right` 这一位置，要不要执行循环体内代码**

- 要执行 → `while(left <= right)`
- 不要执行 → `while(left < right)`

## 1、二分场景

1. **循环内部直接 return 找到的 target**（704、33 旋转数组）

> 会用到 left==right 位置，有可能就是答案 写：`while(left <= right)` 边界更新必须：`left=mid+1`，`right=mid‑1`

1. **循环不 return，靠区间收敛，循环结束取`l==r`作为答案（AcWing 模板，找边界）**（35、34）

> 相等就停止，不在循环内处理该点 写：`while(l < r)`
>
> - `r=mid`：mid 下取整 `l+(r‑l)/2`
> - `l=mid`：mid 上取整 `l+(r‑l+1)/2`，防止死循环

> mid 防溢出：面试写`l+(r‑l)/2`；竞赛简写`l+r>>1`（有溢出风险）

## 2、相向双指针（接雨水、两数之和 II，不是二分！无 mid）

> 需要**两个不同下标**，`left==right`相遇点不能参与计算 统一写：`while(left < right)`

## 记忆口诀

1. 二分能 return，用`<=`；二分不 return，收敛拿结果，用`<`
2. 相向双指针，要两个不同位置，一律`<`
3. 终极自问：left 等于 right 的时候，我要不要跑循环里面的代码？要就`<=`，不要就`<`

## 避坑

不要看见`while(l<r)`就当成二分模板，接雨水双指针也用这个条件，但没有 mid。 模板 2 的`+1`只配合`while(l<r)`、`l=mid`，不要抄进`while(left<=right)`代码。
