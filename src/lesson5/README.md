# 动态规划
1. 状态表示：f[i][j]
   1. 集合
   2. 属性：MAX，MIN，数量

状态表示一定要满足，能够将答案表示出来，其次是在此基础(能求出答案)上，维度越低越好。

2. 状态计算
就是集合的划分

时间复杂度计算： 状态的数量 X 状态转移的计算量
# 题目
1. 01 背包问题：每个物品的数量只有一个。
2. 完全背包问题：每个物品的数量是无限的。
3. 多重背包问题：每个物品的数量可以不同。
4. 分组背包问题：将物品分组（比如苹果香蕉一组、番茄土豆一组），每一组中只有一个能放入到背包，即同一组内物品是互斥的。

第二部分：
1. 线性DP
   1. 数字三角形问题思路：f[i][j] 表示从起点走到 (i, j) 这个点的最大路径
      1. f[i][j] = max(f[i-1][j-1]+a[i][j], f[i-1,j] + a[i]j)
   2. 最长上升子序列问题
   3. 最长公共子序列问题
2. 区间DP：即f[i][j]状态表示的时候，表示的是一个区间。比如表示从 i 到 j 这个区间。
   1. 石子合并问题: f[1][N] 是答案

第三部分：
1. 计数类DP
   1. 整数划分
2. 数位统计DP
   1. 计数问题
3. 状态压缩DP
4. 树形DP
