# LeetCode 35 搜索插入位置 —— 个人深度思考笔记（卡点复盘）

## 1\. 题目本质

给定有序数组，找到 **第一个 ≥ target 的下标**，找不到就返回插入位置。

完全等价于：**AcWing 左边界二分模板的标准应用场景**。

## 2\. 我写的初始代码（闭区间写法）

区间：`[0, nums.size()-1]`

```Plain Text
int l = 0, r = nums.size() - 1;
// 手动特判最大值
if (nums[r] < target) return r + 1;

while (l < r)
{
    int mid = (l + r) >> 1;
    if (nums[mid] >= target) r = mid;
    else l = mid + 1;
}
return l;
```

## 3\. 核心卡点（我最大的疑问）

**疑问：左边界模板不是找「第一个 ≥ target」的位置吗？**

**为什么数组全部元素小于 target 时，模板返回的是最后一个下标，而不是插入位置 n？**

### ✅ 终极理解（最重要的结论）

**AcWing 左边界模板只能在你给的区间内找答案！**

- 如果你设置 `r = n-1`（闭区间）

- 搜索范围只能是 `[0, n-1]`

- **如果整个区间没有满足条件的值**（全部数 \< target）

- 模板无法跳出区间，只能卡在 **区间最右端点 n\-1**

所以：

**模板没有错，是区间范围限制了答案！**

## 4\. 两种区间写法的本质区别（彻底弄懂）

### 写法1：闭区间 \[0, n\-1\]（我一开始的写法）

- 优点：所有下标合法，不会越界

- 缺点：无法表示答案为 `n`（末尾插入）

- 必须手动特判：`if (最大值 < target) return n`

### 写法2：左闭右开 \[0, n\)（35题标准最优写法）

- `r = nums.size()`

- 区间天然包含答案`n`（末尾插入位置）

- **不需要任何特判，全覆盖所有情况**

- 是 35 题真正的完美模板

```Plain Text
// 最优、无特判、全覆盖AC代码
class Solution {
public:
    int searchInsert(vector<int>& nums, int target) {
        int l = 0, r = nums.size();
        while (l < r)
        {
            int mid = (l + r) >> 1;
            if (nums[mid] >= target) r = mid;
            else l = mid + 1;
        }
        return l;
    }
};
```

## 5\. 两题模板差异总结（704 vs 35）

### LeetCode 704（找数，找不到返回\-1）

- 必须：`r = n-1`

- 最后需要判断 `nums[l] == target`

- 不能用 `r = n`，会导致访问越界

### LeetCode 35（找插入位置）

- 必须：`r = n`

- 不需要判断、不需要特判

- 天然支持「插到数组末尾」的情况

## 6\. 最终个人口诀（彻底吃透）

1. **左边界模板找的是：当前区间内第一个满足条件的数。**

2. **若无满足条件的数，答案就是区间右端点。**

3. 要能插末尾 → **r = n**

4. 要访问元素防越界 →**r = n\-1**
