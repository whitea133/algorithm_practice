# 48. 旋转图像

题目：https://leetcode.cn/problems/rotate-image/description/?envType=study-plan-v2&envId=top-100-liked

解题思路参考leetcode的题解

## 题解 -- 先转置，后每一行反转即可

代码如下：

```
class Solution {
public:
    void rotate(vector<vector<int>>& matrix) {
        int n=matrix.size(), m=matrix[0].size();

        for(int i=0;i<n;i++)
            for(int j=i;j<m;j++) // 注意这里必须是 j = i,只将由右上半部分交换，即完成装置。j从0开始的话，就相当于没有变化了。
                swap(matrix[i][j],matrix[j][i]);

        for(int i=0;i<n;i++)
            reverse(matrix[i].begin(),matrix[i].end());
    }
};
```

## 复杂度分析

时间复杂度：O(N^2 )，其中 N 是 matrix 的边长。对于每一次翻转操作，我们都需要枚举矩阵中一半的元素。

空间复杂度：O(1)。为原地翻转得到的原地旋转。
